# `metafab build` installs the factory for agent tools

Run `metafab build` to compile `.factory/` into `.claude/skills/` and `.agents/skills/` for the targets in `agents`, with the built-in `metafab` skill, the root `AGENTS.md` factory block, the `CLAUDE.md` import block and the `.gitignore` block. A second run with no source change prints `Up to date.`. `build` removes installed output it owns when a skill or target is gone, and stops with exit code 5, changing nothing, when a selected destination holds anything it did not generate. `--json` reports `{ ok, command, changed, problems }`.
