# Metafab can resolve, download and validate a fab from npm, Git, HTTPS or a local path

Every source form in the sharing spec now parses: `name@range`, scoped npm names, `github:owner/repo#ref`, `git+ssh://` and `git+https://` with a tag, branch, commit or `#semver:` range, an HTTPS tarball, and a local path. Each resolves to an exact version or commit and downloads into `~/.metafab/cache/` (`METAFAB_CACHE` overrides it). npm tarballs are checked against the registry hash and never run scripts. Archives are unpacked safely: traversal, absolute paths, links that leave `.factory/`, special files and files over 1 MB are refused with exit 4.

No command uses this yet, so there is no new CLI output.
