# `npx @seasb/metafab` installs Metafab 2, which reads format 2 fabs such as fab-basic 0.2.x

The package version is `2.0.0`, so once `v2.0.0` is tagged on `main` the release workflow publishes it under `latest`. The README's quick start, `npx @seasb/metafab import github:Traction-Team/fab-basic --agents claude,codex --setup`, then imports fab-basic 0.2.x instead of failing with `Unknown factory format 2`. Format 1 fabs still import. When a `factory.yaml` field is unknown and not close to a known name, as a field a later Metafab adds would be, `check`, `build`, `publish`, `import` and `update` now say to upgrade `@seasb/metafab` as well as to remove the field. The README now covers choosing what agents read (`metafab env set`), staying on 1.x with fab-basic `#semver:^0.1.0`, and the `@next` prerelease channel.

## Still to come

The orchestrator tags `v2.0.0` on the merge commit, records `npm view @seasb/metafab dist-tags` and the provenance, and runs the new-user check in a new Git repository. Plan 2.018 then moves this repository and fab-basic onto 2.0.0. The store ships as 2.1.0.
