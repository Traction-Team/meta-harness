# There is a first fab to import, and this repository's factory now comes from it

`fab-basic` (`@seasb/fab-basic` on npm, source in `github:Traction-Team/fab-basic`) is a ready-made factory: plan, build and review work one pull request at a time, with Orca and OpenCode or Amp workers, stacked pull requests and releases as settings that default off. `metafab import @seasb/fab-basic --setup` creates `docs/factory.md`, `opencode.json`, `orca.yaml` and `docs/roadmap.md` and leaves one value to set, `verify`. This repository imports it: its own values are in `docs/factory.md`, and factory changes now arrive with `metafab update` (already used once, 0.1.0 to 0.1.1). `next.mjs` now names an unplanned roadmap line after its bold text or the text before its first `: `, not its first link.
