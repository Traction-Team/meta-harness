# `@seasb/metafab` is ready to publish as 1.0.0 from a tagged release

The package is at `1.0.0`, ships a README with the install options (`npx`, `pnpm dlx`, `bunx`, a devDependency) and the quick-start, and a `v1.0.0` tag pushed from `main` runs `.github/workflows/release.yml`, which checks the tag against `package.json`, runs `npm run verify` and publishes with npm trusted publishing and provenance. The spec's quick-start now imports `github:Traction-Team/fab-basic` with `--setup`: `npx @seasb/metafab import github:Traction-Team/fab-basic --agents claude,codex --setup`. Nothing is on npm until the person bootstraps the package and pushes the tag.
