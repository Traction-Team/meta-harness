# `metafab publish` releases the factory as a fab to npm, a Git fab repository, or both

Add a `publish` section to `.factory/metafab.yaml` and run `metafab publish`. It runs `check`, stages `.factory/` without `metafab.yaml`, `.factory/README.md` and your `publish.exclude` globs, adds a root README (and a `package.json` for npm), and confirms the version is new on every target before it publishes to any. `metafab publish --dry-run` prints the files, size and targets and touches nothing; `--tag` sets the npm dist-tag. A fab repository edited by hand is refused with exit 5, and a re-run after a partial failure skips the target that already has the identical release. The project repository is never changed.
