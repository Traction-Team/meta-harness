# `metafab check` validates the whole factory in one command

`metafab check` reports factory and configuration problems, unresolved conflict markers and `.upstream` files under `.factory/`, and installed output that does not match what `metafab build` would write: missing skills after a fresh clone, hand edits, wrong file modes, stale `AGENTS.md`/`CLAUDE.md`/`.gitignore` blocks and an out-of-date built-in skill. Each problem prints as `file:line: level: message` with a `fix:` line; `--json` gives the same list. It exits 1 on any error.

`metafab build` also got sturdier: an unreadable installed path is one `Cannot read <path>` error (exit 1) instead of a stack trace or an ownership conflict, and installed files with the wrong mode (0666, 0444) are repaired.
