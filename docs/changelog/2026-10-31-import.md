# `metafab import` brings a shared fab into your repository

`metafab import <source> [--agents <list>] [--force] [--adopt]` copies a fab from a local path, a Git repository, an npm package or an HTTPS tarball into `.factory/`, records it as the upstream in `.factory/metafab.yaml`, installs it for your agents, and prints a review summary. The summary puts the riskiest changes first: code that runs on your machines, then files that change every agent session, then workflows, skills and other files. Nothing is committed.

Import stops before it writes anything when a fab file would replace different local content (use `--force` to replace it), or when the factory already has an upstream. Temporary fetch directories are now removed, and a link with a missing target is reported once.
