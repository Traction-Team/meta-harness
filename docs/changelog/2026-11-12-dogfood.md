# This repository installs its own factory with `metafab build`

Metafab now builds Metafab's factory: `npm run factory` runs `node dist/cli.js build`, checks the committed `AGENTS.md` block is current, and runs `metafab check` with no problems. The skills in `.claude/skills/` and `.agents/skills/` are ignored generated copies instead of committed symlinks, and `.factory/scripts/link.mjs` is gone. A new Orca worktree gets every skill, including `metafab`, from the committed `orca.yaml` once the Orca repository setup command is cleared. CI runs the same build-and-check recipe the spec gives to users.

## Still to come

Git hooks stay off here (`git-hooks: false`) until `@seasb/metafab` is on npm; Plan 1.012 turns them on. Until then, run `npm run factory` after a checkout or merge that changes `.factory/`.
