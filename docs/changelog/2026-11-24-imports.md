# A workflow or `.factory/AGENTS.md` can import one shared partial instead of repeating it

A line `<!-- factory:import ../../partials/sub-agents.md -->` in any `.md` file of a format 2 factory is replaced by that file's body, without its frontmatter, and its `when` and `switch` blocks render for the importer's selection (every value, labelled, in the root `AGENTS.md` block). Partials go in `.factory/partials/` by convention, and partials can import other partials. `metafab check`, `build`, `import` and `publish` reject an import that is absolute, uses `\`, is not `.md`, leaves `.factory/` (also through a link), differs in letter case, is missing, unreadable or binary, or loops, on the directive's line. They check imports inside removed blocks too. Format 1 factories keep an import line as text, with a warning.
